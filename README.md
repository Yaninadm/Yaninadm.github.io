# Yanina Di Marzio · Portfolio profesional

Portfolio en español con 18 proyectos y experiencias en 7 áreas: administración, datos e IA, diseño, libros, audiovisual, teatro y coaching.

## Contenido

- Proyectos filtrables por área, con detalles y muestras.
- Presentación de experiencia, herramientas y formación.
- CV y muestras descargables.
- Contacto por correo y LinkedIn.

Las fichas distinguen experiencia laboral, muestras ilustrativas y proyectos en desarrollo. El dashboard no contiene bases de profesionales. El chatbot tiene un guion preparado y no es un servicio operativo.

## Edición

Los archivos del sitio están en la raíz del repositorio. Editar `index.html` para textos y proyectos, `styles.css` para la apariencia y `app.js` para los filtros. Las imágenes y archivos descargables se encuentran junto a ellos.

El sitio es estático: no requiere claves, servicios de pago ni instalación. Puede abrirse localmente con `index.html` y está preparado para GitHub Pages desde la rama principal y la carpeta raíz.
